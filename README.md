## Features

- [x] Hero, vision and mission, and history timeline
- [x] Photo slideshow with captions, thumbnails and swipe
- [x] Plan your visit section with Google Maps directions
- [x] Ministries, giving details and contact links
- [x] Mobile menu button, dark mode and responsive layout

## Getting started

```bash
git clone https://github.com/<your-username>/<repository-name>.git
cd <repository-name>
```

Open `index.html` in any browser. No build step is needed.

<details>
<summary><b>Deploy with GitHub Pages</b></summary>

1. Push the repository to GitHub.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<your-username>.github.io/<repository-name>/`.

</details>
